---
name: claudemd-creator
description: "Use when the user asks to create, update, or regenerate the CLAUDE.md file. Produces a brief project description and an index of docs/ with descriptions."
---

Create or update `CLAUDE.md` at the project root with only:

1. A one-sentence project description (derived from README, package.json, etc.)
2. A bulleted list of each file in `docs/`, with a one-line description of what it covers

No other content. Overwrite any existing CLAUDE.md entirely.
